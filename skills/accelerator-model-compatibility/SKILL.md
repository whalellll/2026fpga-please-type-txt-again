# 加速器通用性优化

读取当前硬件能力、寄存器、UAPI、驱动范围检查、转换器和模型元数据。
从当前工程重建算子和资源能力表。ABI1、NHWC4、scratch 大小与 S8 量化等具体
配置来自 Pango 案例，迁移时使用新工程真实约束，不要求新工程实现同名 ABI。
模型名称或“卷积”标签不能证明硬件可执行。按需读取
[分块与兼容性经验](references/lessons.md)。

## 建立算子契约

列出形状、布局、signedness、累加宽度、回绕/溢出、bias、激活、舍入、比例、
饱和、对齐、地址单位、scratch 容量与最大维度。能力表区分原生、CPU 辅助分块、
CPU 执行和未支持；对每类保存独立参考及故意拒绝的输入。

从实际 GET_INFO / feature bits 和 ABI 版本选择实现，不由编译成功猜测板上能力。
新增能力保持原 dense、sparse/Pikafish、卷积 ABI 和寄存器兼容；旧测试及多 fd
隔离必须继续通过。可使用新 ABI/能力位明确扩展，但不能改变旧参数语义。

## 分块大维度模型

- Pango ABI1 探针按输出像素、K、输出通道分块；新工程合法限制来自本版 guard/UAPI。
  输入 NHWC、权重 OIHW 与物理交错格式分别定义；尾槽补零、尾输出紧凑保存。
- 深 K 每段返回无 bias/无激活/无移位的 INT32 部分和。按独立参考合并全部 K
  段，bias 只加一次，最终一次 requant/激活。中途量化会破坏正负抵消。
- 先核对部分和是否能用硬件宽度准确表示；软件 INT64 合并不能修复已经溢出的
  单段 INT32。定义总和范围和越界拒绝，而非静默截断。
- 测 Cin/Cout 尾块、K 超限分段、跨行窗口、padding、stride、1×1/3×3/6×6、
  零数据、极值、边界地址和哨兵。某版本物理 lane 与工具分块大小不必相同。
- 计算每作业暂存、DDR 流量和作业数，计入 CPU 展开/打包/合并/调度成本。
  分块支持模型形状，不意味着达到了目标帧率。

## 完整模型与兼容性

保持训练模型的 SiLU、anchor、stride、类别顺序、RGB/letterbox 等语义。Conv+BN
融合和 W8A8 校准需逐层黄金张量与独立测试集；固定 shift 的局部探针不代表完成
校准。不支持的 SiLU、残差、Concat、池化、Upsample、Detect/NMS 显式在 CPU 执行
并计时，或作为独立扩展先测试，不换成更容易执行的不同算子。

版本化模型清单包含权重/数据哈希、布局、量化、层拓扑和偏移。拒绝坏版本、CRC、
截断、范围溢出和未知能力。真实硬件证明使用严格设备模式；生产回退政策与性能
证明分开定义。旧模型、语音与 NNUE 并发兼容须由同版系统测试，不能由 ABI 不变
直接推出。交付时记录已支持算子、CPU 边界和待完成项。
