# 加速器性能优化

先读取当前工程的 AGENTS.md、README、性能 TODO、RTL 周期寄存器定义及 runtime。
建立本工程配置表：器件、时钟、工具链、引擎模式、总线、模型和向量哈希。
发现缺失计数器时先增加不改变功能的观测或使用已有计时接口。
本技能可在不同工程使用；Pango 的数字与路径仅是参考案例，不能移作当前配置。
需要比较方案或解释已有测量时，读取 [经验与证据](references/lessons.md)。

## 固定测量工作量

- 区分核心周期、硬件作业、整层、NNUE evaluation、UCI 搜索和摄像头到识别结果。
  先定义用户目标。Pango 案例的 10 ms NNUE 口径包含两个视角 accumulator/transform、PSQT、FC0/1/2 与整数后处理；
  不含模型装载或整步搜索。30 fps 应包含约定的采集、预处理、完整图和后处理。
- 固定输入、模型、搜索深度/节点及 TT/history 条件。改变搜索截止检查频率、节点数
  或模型精度，不能算等工作量硬件加速。冷/热缓存和首次上传分开记录。
- 用独立整数参考核对结果，再计时。旧路径先测，按本地 TODO 写正确性/周期/字节
  测试后实现。尾通道、溢出、饱和、背压、abort、最大输出和跨 4 KiB burst 要覆盖。
- 拆分装载、CPU 展开/打包、复制、锁等待、DMA、核心、部分和合并、requant、SiLU
  和其他 CPU 算子。报告重复次数、均值、P50/P95、DDR 字节、周期及测量范围。
  理解计数器事件；`out_valid && !out_ready` 不自动等于 DDR stall。

## 由瓶颈选择改动

- 当布局利用率或布线压力偏高时，先用当前整机原生映射报告定位 LUT、FF、分布式
  RAM、块 RAM、DSP 和物理逻辑簇的主要使用者；保留功能、整数结果及周期基线。
  优先试验可回退的资源改写，先做定向仿真和整机综合，再比较资源与关键路径。
  只有收益有证据、性能损失有明确上界并被目标允许时才启动完整布线；更换 seed
  或反复提高路由迭代次数不能代替这一步。资源门槛通过不等于物理时序通过。
- 用 MAC 数/每拍并行度/频率和总线字节/带宽下界判断目标是否可达；明确下界所用
  的串行、并行或重叠假设，不把理想下界当成测量。
- 输入/权重装载占优时，优先调查跨 tile 复用、常驻模型、输入复用和作业提交次数。
  要计入 scratch 被另一 fd 覆盖后的恢复成本。候选复用策略先测命中/失效/切换。
- 输出或后处理占优时，验证准备下一 lane 与写当前 lane 的重叠、DMA 连续输出，
  并保留数值和地址布局。软件合并深 K 时，只在最终完整和上量化。
- LUT 高时，从实际 PDS 映射寻找多端口缓存、宽 mux 和重复算术。小缓存可按银行
  改同步/分布式 RAM；同时验证端口冲突、读写同址和周期。one-hot、窄位宽或 DSP
  打包都需要实测，不能靠编码风格推断资源下降。
- 收窄内部计数或用递增地址替换索引乘法时，保留公开字段的完整范围检查，
  证明累计计数/步长/地址的边界，验证尾 tile、4 KiB、背压与错误恢复的周期和字节。
  小模块映射可用于筛选，最终取舍依据同版整机映射；局部收益可能在整机中反向。
- 若提高并行度，核对 APM/DRM/LUT 容量、低通道利用率、数据供给及最终时序；孤立
  乘法探针通过不代表已集成进整机。

## 验收与记录

同一源码上通过定向仿真、相关 SoC/软件回归、原生整机资源与工具要求的全部时序角后，再以
匹配位流和启动文件板测。严格设备模式禁止静默 CPU 或 `/dev/mem` 回退。
复测旧 dense、Pikafish、语音和不同数据多 fd 竞争，记录队列与音频溢出。
归档基线/候选哈希、输出比对和计时日志；分别写仿真通过、物理通过与板测状态。
只发布实测范围内的收益，按本地 TODO 条件提交和交付，并更新本 skill 的适用经验。

## 计时校准

发布绝对时间或倍率前，将系统时钟与独立硬件计数器/外部时间作对照。
分辨率正常不证明时间准确；发现偏差时撤回受影响的均值、分位数和相减余量，
保留 raw 记录，不按统一比例换算不同负载。诊断计时改动保留原优化/链接参数；
只读计时器须核对本工程地址与频率，不能借此绕过加速器 owner 或隐式回退。

## 分阶段剖析

若完整 host 时间仍有大块未归类，给诊断副本增加层级计时，验证样本数、视角数、
tile/job 数和父子耗时闭合。父计时包含子计时；展示占比时使用互不重叠的阶段。
保留原程序，比较探针关闭、开启及前后原程序，区分编译布局变化、计时开销与运行波动。
在较慢的 CPU 上可累计原始硬件计数，区间外统一换算；校准读计数与记账开销，
不要假设探针无成本，也不要从每个阶段机械扣除同一个平均数。

不同合法作业大小的微测试可检查固定提交成本与随流量/计算增长的成本；仍应去掉预热，
用独立整数结果检查输出，记录实际周期和由 ABI 推导的复制字节。复制字节不是 DDR
总线实测流量。ioctl 总时间减硬件周期仅得到其余路径的合计，内部复制、锁、寄存器、
轮询与调度尚需进一步观测，不能凭差值给其中某项命名。
