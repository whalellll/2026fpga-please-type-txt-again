## 作品信息
1. 作品名称：中国象棋RISC-V对弈平台
2. 作品简介：本作品面向紫光同创 FPGA 平台，构建以自主设计 RISCV处理器为核心的边缘智能 SoC。采用软硬件协同设计，构建集语音识别、图像识别、键鼠操作、AI 对弈、屏幕显示与语音播报于一体的棋类交互系统。作品面向不便使用键鼠的用户及普通棋类爱好者，适用于家庭娱乐、社区棋类活动与棋艺辅助训练，旨在让用户通过适合自己的操作方式参与对弈。
系统支持实体棋盘，支持用户通过键盘鼠标在屏幕棋盘上走棋，也支持通过麦克风输入走棋、局面查询及对局控制指令。AI 的走法与棋局变化通过屏幕和语音反馈，界面同步提供局面评估、棋谱记录与响应延迟信息。语音交互覆盖开局、落子、确认、取消、查询和结束等关键环节，结合指令复述与错误提示，降低误识别造成的误操作风险，为不依赖屏幕的独立对弈提供支持。
项目将围绕 FPGA 接口与实时控制逻辑、双模态交互和错误恢复开展设计，通过语音指令识别效果、完整对局成功率、状态一致性、端到端响应延迟及硬件资源占用等测试，评估系统的可用性与工程实现效果。
3. 板卡：盘古676系列开发板100 Pro+
4. 题目：赛题1 CPU 设计

## CPU从何而来

在这里我将会回答我们的 CPU 架构是怎么确定的：

1. 源头：我们2026届龙芯杯“请输入文本队”的乱序CPU处理器
[github链接](https://github.com/26nscscc-HITSZ-PleaseTypeText)

2. 改动：
- ROB大改，从原本的ARF改成了PRF，不沿用马家沟核队伍的设计了。**队长原话：“这些是ai集众家之所长，不过改成prf之后龙芯延续的就少了”**
- 前端小改，集中在分支预测
- 后端改成了纯粹的双发乱序，去掉了我们的三发部分
- cache 从16KB改成了8KB，并去掉L2 cache，同时因为容量变小了，所以变二路组相联了。
- 对代码具体细节做了许多改动，以追求更高的频率。**队长原话：“但是在时序调节细节上应该每一版有每一版的不同”**
- 做成了龙芯未完成的访存投机（参考了中科大付爷爷的国特CPU）
- 还有很多精简设计的改动（见VexRiscv开源cpu）。**队长原话：“其实我觉得影响最大的vex那个核，真的是非常mini精简的一个优越开源核，对后端”**
- **“不过还是没有放下我的超绝大前端”**（队长原话）

3. 曾经的思路：
- 龙芯杯的胡✌的个人赛国一CPU
- VexRiscv开源cpu
- 中科大付爷爷的国特CPU

这些都由于不适配之类的而放弃了（应该是“不适配”这一原因吧）。但这些作品启发了我们一点，先写chisel再转verilog的开发方式，更方便迭代与AI开发

4.结果：实现了coremark 6.033，125MHZ的CPU处理器（11.8）
