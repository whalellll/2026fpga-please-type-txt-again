## 作品信息
1. 作品名称：中国象棋RISC-V对弈平台
2. 作品简介：本作品面向紫光同创 FPGA 平台，构建以自主设计 RISCV处理器为核心的边缘智能 SoC。采用软硬件协同设计，构建集语音识别、图像识别、键鼠操作、AI 对弈、屏幕显示与语音播报于一体的棋类交互系统。作品面向不便使用键鼠的用户及普通棋类爱好者，适用于家庭娱乐、社区棋类活动与棋艺辅助训练，旨在让用户通过适合自己的操作方式参与对弈。
系统支持实体棋盘，支持用户通过键盘鼠标在屏幕棋盘上走棋，也支持通过麦克风输入走棋、局面查询及对局控制指令。AI 的走法与棋局变化通过屏幕和语音反馈，界面同步提供局面评估、棋谱记录与响应延迟信息。语音交互覆盖开局、落子、确认、取消、查询和结束等关键环节，结合指令复述与错误提示，降低误识别造成的误操作风险，为不依赖屏幕的独立对弈提供支持。
项目将围绕 FPGA 接口与实时控制逻辑、双模态交互和错误恢复开展设计，通过语音指令识别效果、完整对局成功率、状态一致性、端到端响应延迟及硬件资源占用等测试，评估系统的可用性与工程实现效果。
3. 板卡：盘古676系列开发板100 Pro+
4. 题目：赛题1 CPU 设计
