# CPU125 FPGA SoC 评委快速开始

本目录对应 performance_soc 提交 `dfb849e6a6df77eb90d1a066c1b8bc3c493f1a08`，CPU 125 MHz，SYS 49.5 MHz。工程目标器件为 PG2L100H-6-FBG676，位流由 PDS 2025.2 build211867 生成。

## 加载与复测

1. 核对 `01_运行文件/版本与校验/` 的版本和 SHA256，选用 `01_运行文件/FPGA位流/soc_top.sbit`。
2. 连接匹配的板卡和 JTAG，在 PDS 下载工具中扫描并确认 PG2L100H 后，将该位流加载到易失性 CRAM。随附 BIN 用于归档核对，现场加载选用 SBIT。
3. 打开板卡串口，设置 115200、8 数据位、无校验、1 停止位。预期进入启动控制台，输入 `info` 核对 CPU_HZ=125000000 和 SYS_HZ=49500000。
4. 输入 `coremark` 运行性能模式，输入 `coremark validate` 运行验证模式。保存原始串口输出、CRC、运行时长和位流哈希。正式结果应记录三次性能运行和一次验证运行，核对每次正式计时达到至少 10 秒。

## 文件入口

- **01_运行文件**：加载位流、与位流配套的固件和校验清单。固件已随位流绑定，ELF 用于查阅符号。
- **02_工程源码**：工程入口为 `pds/soc_gui.pds`，原有相对路径保留。建议在短路径的副本中打开工程。构建输入以 CPU125 的 `03_验证材料/PDS时序与资源/build_snapshot.json` 为准。
- **03_验证材料**：全角时序、资源、物理回读、CoreMark CRC 与 IPC 仿真、实板复测状态。复现包可解压到独立短路径目录。
- **04_参赛文档**：版本摘要、系统结构和工程说明。

当前候选版已通过 PDS 全角时序、物理约束回读及短程 CoreMark RTL 仿真 CRC 核验。CPU125 的实板 CoreMark、模型并发和直接 SD 启动待验。上述板卡步骤供现场复测。

## 启动介质与模型

01_运行文件/启动介质内提供 SD8 启动及模型文件 ZIP、原始版本清单、rootfs 内容清单和操作说明。解压 SD8 ZIP 后可直接取得八个待写入 FAT32 根目录的文件。该套启动介质源自 CPU120 交付，搭配本包 CPU125 位流的现场复测仍待完成。

## RTL 交付范围

SoC 顶层为 rtl/soc/soc_top.v，CPU 实现为 rtl/cpu/CoreTop.sv。综合与仿真 RTL 使用 Verilog/SystemVerilog。DDR IP 附带的 VHDL 实例化示例按原始清单保留。
