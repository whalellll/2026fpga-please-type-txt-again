# 第三方来源、许可与固定输入

## CPU V3.5 候选与历史 VexRiscv

V6.5 候选的 CPU 来自独立 `src` 仓库的 CPU V3.5 Chisel 工程；`rtl/cpu/source.json` 记录实际导入的源提交、生成输入和 RTL 哈希，`scripts/sync_cpu.ps1` 完成原样同步。集成包装层为 `rtl/cpu_top.v`。版本目标不替代来源身份或最终验收记录。

V5.4 使用的 `rtl/vendor/VexRiscv_Linux.v` 与 YAML 已从当前构建移除。其历史来源为 litex-hub/pythondata-cpu-vexriscv 生成物：
取用提交642ecfed1c84460555d6d803d660cc60cfc1ecb6；SpinalHDL1.9.4，
VexRiscv hash056d57f5a3cd0ccd7fef861480c4cc0878e183fa。
旧版本将CLINT/SoC MMIO设为非缓存，补充S模式cycle/time/instret、
OpenSBI所需misa/medeleg/mideleg及mtvec读映射。
这些历史特性不代表当前 CPU V3.5 的特权模式能力；当前 CPU 只启用 M 模式。
许可保留 [VexRiscv MIT](LICENSE-VexRiscv.txt)、[pythondata BSD](LICENSE-pythondata-cpu-vexriscv.txt)。

## Linux / OpenSBI

Linux5.14 Image与Buildroot2021.11-git /BusyBox1.33.1基线rootfs来自
LiteX VexRiscv的linux_2022_03_23.zip预编译资源。
make_rootfs.ps1只替换inittab/profile/rcS，由附带基线和overlay精确复现。
附linux/sources/opensbi-1.3.1.tar.gz；fw_jump.bin为本工程固定地址版本。
当前没有linux-5.14.tar.xz，不声称完整Linux/Buildroot源码重建。
边界见 [固定输入](../prebuilt/README.md)。
来源：https://github.com/litex-hub/linux-on-litex-vexriscv/issues/164 、
https://github.com/riscv-software-src/opensbi/releases/tag/v1.3.1 。

## Pango / HDMI / Ethernet

DDR、PLL与行缓冲IP保留Pango生成源、IDF引用文件及厂商头部/许可。
内部引用的仿真库、模板和示例保留。
HDMI PLL、MS72xx/I2C初始化与ASCII字模来自用户提供的soc_plus；
文件头分别标注Pango/Meyesemi。终端FIFO、80×20终端、自绘标题和>_图标为本工程实现，
gen_hdmi_header.ps1直接生成像素，不依赖Linux Tux图片。
RGMII参考随板2_11_ethernet_test的管脚、DDR I/O原语和延迟结构。
ip/ref_clock/ref_clock.v保留来源参考，但100 Mbps顶层使用PHY的25 MHz RXC，
不实例化该1 Gbps PLL。工程增加MMIO、ARP/IPv4/UDP/TFTP、采样窗扫描、
offset/hexcrc和camera可靠UDP。
