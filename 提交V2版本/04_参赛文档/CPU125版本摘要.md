# CPU125 版本摘要

```text
上位机 ── JTAG ── FPGA 配置
上位机 ── UART ── 启动控制台
                     │
CPU 域 125 MHz ── AXI 跨时钟桥 ── SYS 域 49.5 MHz
       │                               │
    RV32 CPU                      启动 ROM / 外设
```

CPU 为 V3.5，采用 RV32IMA、Zicsr、Zifencei 与 Zbc。CoreMark 编译方案为 cm60-unroll2-lto-branch1。PDS CPU 慢角建立与保持余量分别为 +0.139 ns 和 +0.121 ns。工程资源与完整时序结果见 CPU125 位流清单及验证材料。

评委可从根目录快速开始文档加载位流并在启动控制台运行 CoreMark。工程原始说明保留了版本背景。正式参赛报告可在本目录补入。
